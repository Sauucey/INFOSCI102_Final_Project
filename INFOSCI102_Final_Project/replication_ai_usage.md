## Project Overview

The **Creative Energy Tracker** is a Python-based Streamlit web app I built to help people (and myself) understand how different daily activities impact more than just productivity. Instead of just checking off tasks, this app tracks **Energy, Focus, Enjoyment, Meaning, and Stress**. By logging these over time, the app identifies patterns—like which activities lead to a "Creative Flow" state and which ones are just "Fun but Distracting."

## Setup and Installation

To get this project running on a Windows machine, I followed these steps in Vs Code terminal with the project folder open:

1.  **Create a virtual environment:**
    ```powershell
    python -m venv .venv
    ```
2.  **Activate the environment:**
    ```powershell
    .\.venv\Scripts\Activate.ps1
    ```
3.  **Install dependencies:**
    ```powershell
    pip install -r requirements.txt
    ```
4.  **Launch the app:**
    ```powershell
    streamlit run app.py
    ```

#### Data Requirements
This project does not require external datasets or API credentials. All data is generated by the user through the app interface.
*   **`activities.txt`**: Automatically generated on first run with default activities.
*   **`energy_logs.csv`**: Automatically generated when the first activity is saved.

### Launch and Interaction
1.  **Launch:** Run the command `streamlit run app.py` from your activated terminal.
2.  **Navigation:** Use the sidebar on the left to switch between pages.
3.  **Logging:** Go to "Log Activity," fill out the sliders (1-10), and click "Save."
4.  **Analysis:** Go to "Analyze Patterns" to see charts and the AI-generated summary.

#### Example A: The `ActivityLog` Class (`energy_logic.py`)
I wanted to use a bit of Object-Oriented Programming (OOP) to keep my data organized.
```python
class ActivityLog:
    def __init__(self, date, activity, energy, focus, enjoyment, meaning, stress, notes):
        self.date = date
        self.activity = activity
        self.energy = int(energy)
        self.focus = int(focus)
        self.enjoyment = int(enjoyment)
        self.meaning = int(meaning)
        self.stress = int(stress)
        self.notes = notes
```
*   **What AI helped with:** It suggested the structure for the `__init__` method and how to convert the ratings to integers immediately.
